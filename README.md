# Ceres SDA Church: redesign preview (Field Guide)

Lean, mobile-first preview of a new site for the Ceres Seventh-day Adventist Church, 1633 Central Ave, Ceres, CA.
Not the live site. Every page carries `noindex`; yellow highlights are placeholders to confirm.

Pages: Home, Plan Your Visit, Calendar, Bulletins, Watch (+ 404). Static HTML and one CSS file; no framework.
Weekly updates: add the new bulletin to `BUL` (newest first) and rebuild.

Photo credits appear under each landscape plate. Seal and icons are original line art.
